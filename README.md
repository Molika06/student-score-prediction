# Student Score Prediction System Using Machine Learning

## 1. Project Overview
This project predicts an estimated student exam score using study hours, attendance percentage, previous score, and sleep hours.

## 2. Objective
The main objective is to demonstrate how machine learning can predict a numerical exam score using Linear Regression.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 4. Dataset Description
The project uses a dataset containing 120 artificially generated student records.

Features:
- Study Hours
- Attendance Percentage
- Previous Score
- Sleep Hours

Target Variable:
- Exam Score

Note: The dataset is synthetic and does not contain real student records.

## 5. Machine Learning Algorithm
Linear Regression is used to predict the student's exam score based on the input features.

## 6. Evaluation Metrics
The model is evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

## 7. How to Run the Project
1. Open the Jupyter Notebook in Google Colab.
2. Upload the CSV dataset if required.
3. Run the notebook cells in order.
4. Review the visualizations, evaluation metrics, and prediction results.

## 8. Limitations
The dataset is synthetic. Therefore, the model's results do not establish its accuracy on real student data. Predictions are estimates and are not guaranteed exam scores.

## 9. Conclusion
This project demonstrates a basic machine learning workflow, including data analysis, visualization, model training, evaluation, and score prediction.
